```
Design Requirements
1. Persistent Simulation World

The environment should exist independently of the organisms inhabiting it.

Requirements
Persistent world state
Spatial representation (initially 2D)
Deterministic updates
```

```
Deliverables

By the end of Sprint 1 you should be able to:

Create a world.
Advance simulation ticks.
Spawn objects.
Store objects in space.
Update every object once per tick.
Remove objects safely.
```
